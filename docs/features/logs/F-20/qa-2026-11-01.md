## Findings

### M1 · spec · AC10: the two accent focus cues the committee kept are not marked `ponytail:` in code
The feature file's decision ("the chart point's accent stroke and the skip link's accent border stay (marked
`ponytail:`)"), committee OQ-8 and plan §7 all say these carry a `ponytail:` comment. Neither does.
Repro: `grep -n ponytail app/globals.css` shows only the `.switch.current` and the 94 px bar comments; lines 169
(`.chart a:focus .hit … stroke: var(--accent)`) and 304-305 (`.skip-link … border: 2px solid var(--accent)`) have none.
Fix: a `ponytail:` comment on each naming the limit (focus shown in `--accent`, not `--focus`) and the next step
(a DS-27 follow-up), and list both in the PR hand-off.

### M2 · bug (test) · AC12: the "no literal floor below 3" guard misses `d >=` and every floor between 3 and its real value
`F-20 AC12: no contrast test compares a ratio or ΔE00 with a literal below 3` only matches the names `r|min|ratio|de|
contrast(…)|cvdMin(…)` and only rejects literals below 3.
Repro 1: in `lib/a11y-contrast.test.ts` change the AC5 gain-vs-loss assertion `d >= FLOORS.cvd` to `d >= 2`: all 67
tests pass (the loop variable is `d`, which the regex does not list).
Repro 2: in `lib/fixes-cycle2-a11y.test.ts` change `min >= 9` (line 80, the #26 ΔE00 floor) to `min >= 3` and `r >= 4.5`
(line 62) to `r >= 3`: both files, 88 tests, pass.
Lowering `FLOORS` alone does fail (good, see below), so AC12 as worded ("floor constant") is met, but the inline floors
the old tests keep can drop from 9 → 3 and 4.5 → 3 unnoticed. Fix: per-kind minimums (ΔE comparisons ≥ 9, text-ratio
comparisons ≥ 4.5), include `d`, or route the old tests' literals through `FLOORS`.

### L1 · bug (test) · AC7: a rule placed inside the TOKENS block hides its literals
The scanner blanks the whole TOKENS region, and the AC1/AC7 tests only check `:root` rules outside it.
Repro: insert `.sneak { color: #ff0000; }` just above `/* end TOKENS */`: `lib/colour-literals.test.ts` and
`lib/a11y-contrast.test.ts` pass (71/71). Fix: assert the TOKENS block holds only `:root` rules (and the light media query).

### L2 · bug (test) · AC7: scanner heuristics miss two shapes (documented `ponytail:`)
- A named colour through a constant: `const INK = 'crimson'; … { color: INK }` passes.
- A hex inside markup in a string: `'<svg><rect fill="#ff0000"/></svg>'` passes (the `"` before `#` is not a colour
  context). No such string exists in the repo today.

### L3 · spec (doc) · the light Flat-vs-gain tritan figure is misreported
The test prints `light Flat vs up: protan 2.8, deutan 7.0, tritan 19.5`; the feature file's Decisions, the committee log
(build round 1) and the test comment say tritan 31.4. The failing value (protan 2.8) is right; correct the 31.4.

### L4 · note · `--accent` as text is not a named pair
`.watch .watch-btn` (`app/t/[symbol]/Watch.tsx`) is `--accent` text on `--surface`, and on a 15% accent tint when
pressed. The pair list tests `--accent` only at the UI floor (3:1). Measured: 7.10 / 5.54 light, 6.61 / 5.21 dark, so it
passes 4.5 today, but nothing holds it there. Suggest adding it to `PAIRS` at the text floor.
